# Gesichtsunfall - Global Game Jam 2026
Use your driving skills to follow the mask pattern - the more accurately you drop the right colors the more points you'll get.

![Title Image](https://ggjv4.s3.us-west-1.amazonaws.com/files/styles/sidebar_full/s3/games/2026/869244/featured/banner.png)

A silly 3D game developed for the Global Game Jam 2026 in Karlsruhe. [GGJ26 entry](https://globalgamejam.org/games/2026/gesichtsunfall-4)

![In-Game](https://ggjv4.s3.us-west-1.amazonaws.com/files/styles/flexslider_full/s3/games/2026/869244/screenshot/screenshot_1769956261.62563.png)

Support for multiple faces and multiple masks with a built-in level editor.

![Level Editor](https://ggjv4.s3.us-west-1.amazonaws.com/files/styles/flexslider_full/s3/games/2026/869244/screenshot/level_editor.png)

The level editor saves to:
- Windows: `%APPDATA%\Godot\app_userdata\Gesichtsunfall`
- macOS: `~/Library/Application Support/Godot/app_userdata/Gesichtsunfall`
- Linux: `~/.local/share/godot/app_userdata/Gesichtsunfall`


## Download
